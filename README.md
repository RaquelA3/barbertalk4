# Proyecto de la Barberia
## Este repositorio contiene todos los archivos necesarios para que funcione el frontend del proyecto

Para poder hacer uso de este proyecto se necesita instalar todas las dependencias con el siguiente comando
### npm install

De igual manera el dominio en el que esta alojado es el siguiente
## https://barbertalk4.onrender.com/
Usamos el dominio de render, pero como es un sitio web estatico, no tarda en cargarlo.
